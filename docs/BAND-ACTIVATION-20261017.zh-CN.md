# LTE / NR 锁频段后立即激活

适用于荣悦 E5、T551M、VIPME M8 共用的网页与实体屏幕后端。

## 修正

- 原 `t551m-radio-restart --settings` 使用 ModemManager disable/enable；底层关射频使用 `CFUN=4`，并不等同于 MU300 的 `SFUN=5 → SFUN=4` 协议栈重启。锁定掩码写入后可能未立即激活。代码路径差异已确认；具体群友固件的实际表现未在本轮实机复现。
- 手动应用 LTE / NR、解除频段锁定和恢复默认频段，统一由共享 `lock-control` 调用 `--bands`，通过原 scoped AT owner 执行 `SFUN=5 → 等 1 秒 → SFUN=4 → 等 3 秒 → CFUN?`。
- 只有写入收到自身最终 OK 后才切网；明确失败、缺少终止应答或输入校验失败均直接报错、不切网、不覆盖持久化设置。
- 恢复默认频段需 LTE / NR 两次写入均成功，才执行一次切网；任一步失败不切网，也不保存部分请求。基带已接受的部分写入不会假装自动回滚。开机早期回放仍不切网，既有 AT 顺序、持久化开关和首次拨号顺序不变。
- 原每 SIM 操作锁与 AT 寻址保留；备用卡不操作主卡 WAN，主卡暂停 WAN 后按原 autostart 状态恢复。用户主动关数据不会被强开；射频策略关闭或 CFUN=0/4 时暂缓激活，不强开射频。
- 普通网络模式、小区、手动重连及 VoLTE / VoNR 路径保留原行为。频段仍以自身 OK 确认接受，不要求掩码回读一致。

## 验证

离线回归覆盖成功、拒绝、缺少应答、部分默认写入失败、一次切网、保留旧设置、主备卡隔离、WAN 恢复和射频关闭。网页和屏幕均沿用 `mu300dash.lock_set`，无需另加切网逻辑。

本次未实机部署，未更新此前发布包。
