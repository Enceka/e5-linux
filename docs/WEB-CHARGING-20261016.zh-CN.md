# 网页充电控制补齐（2026-10-16）

## 用户入口

网页「蜂窝 → 设备管理」新增「充电管理」，与屏幕「设置 → 充电」共用：

卡片位于 USB 网卡管理下方，E5、T551M、M8 共用此顺序。

- 启用／关闭充电上限。
- 停止充电阈值：50–100%。
- 恢复充电阈值：20–95%，且必须小于停止阈值。
- 临时充满一次：保留原阈值，达到满电后由原服务恢复上限控制。
- 当前电量、充电状态和上限暂停状态；提供手动刷新。

公共代码供 E5、T551M、M8 使用。没有可写充电控制节点或缺少服务时，显示不可用并禁用操作。
充电限值控制的是电量百分比，不改变 USB 输入电流、快充协议或各机型充电驱动。

## 配置和执行

沿用 `/etc/config/e5-charge` 的 `main.enabled/start/stop/full_once` 和
`/etc/init.d/e5-charge reload`。没有新增第二套配置，也没有新增充电策略进程。
网页保存后屏幕后续读取同一份 UCI；屏幕修改后网页重新进入或点击刷新即可读取。
这些配置仍由原服务在开机应用，系统更新沿用现有的 `/etc/config` 保留流程。

网页新增 `e5-charge` RPC 对象，读权限仅允许 `get`，写权限允许 `configure/full_once`。
后端先校验整数范围和阈值关系，再提交整组配置、重新加载原服务。
服务应用失败会明确提示配置已保存但应用失败，不假报成功。
输入不会拼入 shell 命令；并发网页写请求通过文件锁互斥。

页面打开、手动刷新或保存后读取本地状态，不额外定时轮询、不使用 AT。
中文、英文、土耳其语齐全；样式使用现有主题颜色变量和移动端布局。
