# 2026-10-16 更新日志：E5 / T551M / M8

本页汇总北京时间 2026 年 10 月 16 日的仓库更改，包含当天已有提交和本次提交。
公共功能覆盖荣悦 E5、T551M、VIPME M8；充电芯片、设备树及硬件参数仍按机型区分。

## 电量、充电与省电

- 修正重启后电量跳到 100% 或异常下降的一处已复现原因：电量保存寄存器恢复原厂的读改写方式，保留保存结果校验及错误提示。
- 恢复原厂按实际电压、电流和连续确认判定满电的流程；移除“显示到 100% 就提前判满”和 97% 强制映射 100% 的逻辑。
- 恢复电量平滑及充满后的回充滞回，阈值继续取自本机配置。没有统一提高各机型的充电电流，也没有强制重设电池校准。
- 网页「蜂窝 → 设备管理」新增充电管理，与屏幕共用配置：充电上限开关、停止／恢复阈值、临时充满一次及当前状态。
- 充电管理卡片调整到 USB 网卡卡片下方，三机共用布局，三语言及明暗主题保持一致。
- 按原厂配置启用 CPU 空闲电源管理，修复看门狗在系统挂起／恢复时的处理。
- 修复显示驱动取消未初始化工作项的问题；补齐 GPU、相机电源域的关断、恢复顺序和失败清理。没有更改业务轮询频率或默认关闭热点、IPv6。

## 蜂窝连接与 SIM 状态

- 首次注册、PDP 或获取 IP 遇到明确的暂时失败时，按 1、3、5、7 秒循环重试，无次数上限，并允许随时取消；注册变化导致的拨号取消不会再误关自动连接。
- 失去覆盖后改用注册事件恢复：重新取得有效网络并完成 PS attach 后，由原 netifd 流程继续拨号；修复失败时丢失自动启动标记的问题。
- 保留用户手动断网状态；PIN、APN、鉴权错误不会被无条件自动重拨绕过。
- 接入原厂 ECIND SIM 状态通知，由现有 ModemManager AT 通道确认卡状态。确认无卡后等待状态变化，不反复进行无效的注册／拨号重试。
- 插卡事件仍走原有 SIM 探测与拨号流程，不增加常驻 CPIN 轮询，不改变启动回放、SIM 上电、射频初始化和拨号命令顺序。
- 修复屏幕无卡时残留旧运营商、小区信息，以及把无卡统一显示为“搜索网络”的问题。
- 事件支持以卡座和固件提供通知为前提；不自动切换用户的上网卡，也不关闭基带自身的紧急服务驻留。

## 通话与 Wi-Fi

- 按原厂 RIL 使用指定通话编号的挂断命令；挂断失败时保留通话界面和重试能力，避免界面假装已经挂断。
- 补齐热点客户端列表的 hostapd 回退，并按已关联设备分别读取信息；无法取得的速率保持未知，不使用整个接口的数据冒充客户端数据。
- 兼容更新后的 Wi-Fi 配置生成器，避免已有配置和驱动能力适配遗漏。

## 安装、更新与工具

- 修复 F2FS 缩容检查可能等待不可见交互输入的问题；保留检查失败即停止、先缩文件系统再改分区表的顺序。
- 缩容进度增加进程状态、等待点、累计读写量和最后一行检查输出，便于区分检查仍在运行、等待输入和存储故障。
- 安装器备份、读取与校验 boot／misc／GPT 等数据改用二进制安全传输，避免文本处理破坏原始字节；增加备份进度和诊断信息。
- 修复通过不同版本安装包切回已安装 OpenWrt 时的误判，兼容既有安装布局。临时切换仅备份、校验并修改 misc，不挂载 OpenWrt 根分区。
- 补齐图形安装器的无线 ADB 入口、重启等待、设备身份核对及失败诊断；重写离线使用指南。
- 图形界面以最终安装计划确认作为执行入口，不再在日志里要求输入 yes；缺少参数时明确停止，避免后台读取控制协议输入而卡住。
- 两仓库共享安装器补齐 MU300 旧隐藏空间安装的更新兼容，检查实际布局并保留原容量；提供仅替换 Windows 安装器的补丁流程。
- 接入 Apple Silicon macOS 原生安装器构建与打包流程；不代表本机已经产出 E5 的 macOS 成品。
- Android「op系统切换器」移除测试／调试安装标记，改善普通安装兼容性。
- 默认内置 ttyd、luci-app-ttyd 及翻译，可从网页进入终端；沿用登录认证。
- ModemManager 构建下载增加有界镜像重试，减少镜像故障导致的构建中断。
- 保持只提供 Docker 运行所需的内核支持，不预装 Docker、Xray、sing-box 或其他 VPN 引擎。

- 本次提交前，Windows 安装器测试运行 134 项，通过 130 项，跳过 4 项；SIM 事件、网络恢复、屏幕状态及 ModemManager 构建回归已完成。
- 今天部分电量、省电和恢复修复已在 E5／T551M 上部署检查；M8 本轮完成公共源码适配与构建。不能据此认定三机均完成长期验证。

## 补齐 macOS 安装器

- 正式包默认同时包含 Windows EXE 与 Apple Silicon macOS APP，共用一份系统镜像；缺少任一平台或源码版本不符会停止打包。
- 修复 Windows 重打包造成 Mac 程序失去执行权限的问题；ZIP 保留 APP、ADB、后端和命令行入口所需权限。
- 统一两仓库的 Mac 包目录识别、恢复记录路径及使用指南，刷新 MU300 旧包时同步升级 Mac 命令行入口。
- 本轮仅更新电脑端安装工具与归档，保留此前的系统功能、内核和模块；Mac 为 ARM64 原生版本。
