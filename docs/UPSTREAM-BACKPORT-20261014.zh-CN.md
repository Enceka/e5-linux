# 上游六项修复移植记录（2026-10-14）

本次按用户选定的六项 PR 做针对性移植，保留现有机型识别、双卡配置、安装与更新布局。
此记录描述源码和验证结果；尚未统一编译发布安装包，也没有部署实机。

## 用户可见行为

- 短信转发增加可选成功条件，如 `errcode=0`、`ok=true`。只检查响应 JSON 的顶层简单字段，不把响应内容显示或写入投递日志。未填写时保持原来的 HTTP 2xx 判定；钉钉保留固定成功码检查。
- 预设可填入对应成功条件；旧配置仍可读取，旧客户端未携带新字段时保留已有条件，用户主动清空才撤销。
- 最近投递记录可以确认后清空；不删除短信，不改变转发配置、处理进度或去重状态；清理不会跟随同名符号链接。
- 手动测试至少间隔 5 秒，正常短信转发不受该节流限制。保留本仓库原有的失败不自动重发策略，避免重复投递。
- 中、英、土耳其语及主题继续共用；不引入上游整套页面替换。
- 新增虚拟机 virtio/9p、检查点、MPTCP/组播/MPLS、NFS/CIFS、磁盘映射、USB/IP、UVC 等支持。外设和大部分扩展以模块提供，不增加启动加载列表，不预装 Docker、虚拟机管理器或相关常驻服务。
- 正常启动的权限检查只读；需要纠正时才修改导入文件的权限，不遍历 dev/proc/sys 绑定挂载，不跟随导入树中的符号链接。
- 不修改 NV、运行时 eMMC 省电策略、现有网络/AT 轮询率或温控临界关机阈值。

## 验证

- 实际 Kconfig 合并：E5 6.18、MU300 6.18.54 / 7.2.8，新增配置全部被接受；兼容 NFSv4.1 仅在部分内核单独提供的依赖。
- MU300 两版内核：修改后的虚拟温区模块及应用 EIC 补丁后的驱动对象编译通过。
- E5 原厂虚拟温区适配：在实际 T551M 内核头文件下编译通过，适配可重复执行。
- C 故障测试执行实际温度回调：部分传感器失败仍报告最高有效温度；全部失败返回错误，不制造低温读数；原厂回调最后一个传感器失败也不再丢弃此前有效值。
- 真实 OpenWrt JSON/ucode 集成：两仓库测试 HTTP 200 服务拒收、布尔/字符串成功值、嵌套/无效/超长响应、旧配置、旧编辑器、钉钉、清空隔离与测试节流通过；不访问真实推送服务。
- Chromium：两仓库页面在中英土语言、手机/桌面宽度下测试，成功条件保存和清空二次确认通过。
- 权限、旧归档模式、锁描述符、完整模块与内嵌配置故障测试，以及相邻温控/短信/安装器回归通过。

## 尚待

完整新内核及匹配模块需要重新构建，再统一打包；旧构建产物会被新增检查明确拒绝。
实机启动、TF 插拔、温控异常恢复和真实推送服务验收尚未进行，编译与离线测试不能代替这些验证。
本次不宣称修复了未确定根因的存储损坏或所有“无模组”故障。
