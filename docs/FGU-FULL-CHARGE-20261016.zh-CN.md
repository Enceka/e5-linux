## 目前可确定与不可确定的内容

- 移植源代码存在 97% 满电映射、基于 UI 的满电状态返回，以及特定机型的电压条件。
  这只能说明代码如何运行，尚不能确认它们与 E5、T551M、M8 原厂是否一致。
- AW32257 数据手册能确认寄存器和电流编码，但不能证明原厂是使用硬件终止、
  软件终止，还是在负载存在时采用了另外的收尾方案。默认 TE=0 不等于原厂遗漏。
- 显示 SOC 和常温 SOC 的差异可能来自原厂映射、温度补偿或显示平滑，
  不能直接把合法的 UI 满电记录判为损坏。
- 用户报告 USB 侧和电池侧均约 1A；仍应核对原厂对照中的实测电流、设定电流、
  满充状态及重启前后保存值，不能仅通过固定显示上限处理。

## 后续修复依据

按机型对照原厂驱动／内核模块及设备树，并核对 Android 电池服务的控制接口，
覆盖开机恢复、充满终止、补电与关机保存。只有确认具体偏差后才做最小修复。
公共部分只同步确认相同的缺陷；不同充电芯片继续保留本机策略。
尚未取得充分证据的行为保持原样，不把构造测试通过写成原厂对齐或实机解决。
