# 屏蔽信道扫描

两个仓库采用相同的公共策略，适用于各自支持的全部机型。

- 移除 LuCI「状态 → 信道分析」菜单及其专用 RPC 权限组。
- 原信道分析页面替换为禁用提示，旧链接不再调用扫描或启动轮询；提示支持中文、英文和土耳其文。
- 构建镜像、首次启动、看板服务启动及插件更新时应用策略；上游 LuCI 恢复相关文件后，下次服务启动重新屏蔽。
- 不改无线驱动、手动信道/带宽设置和无线客户端搜索。底层通用 `iwinfo.scan` 仍供无线客户端搜索使用；本次不是删除驱动的扫描能力。
- 不重排基带回放或 AT 命令，不新增轮询服务。

验证：`python3 openwrt/tests/channel-analysis-disabled.py`，需要 Linux/WSL 和 Docker 本地镜像 `mu300-openwrt-base:25.12.5`。两仓库各通过 6 项测试：定向删除、旧页面停用、重复执行不改写、上游文件恢复后重新屏蔽、异常 JSON 不先写菜单、缺少可选状态包、缓存清理范围（其中首项同时覆盖菜单、权限和旧页面）。构建脚本语法检查通过。

已纳入两仓库 r5 安装包，包校验及最终镜像检查通过。后续通过电脑更新 V50，确认该策略及禁用页面已落地；未向其他机型单独热部署此策略。
