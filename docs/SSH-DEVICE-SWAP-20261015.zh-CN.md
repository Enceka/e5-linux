# USB 同地址换机的 SSH 更新兼容（2026-10-15）

## 问题

不同设备与重新安装后的系统会共用 USB 管理地址。安装器曾保存地址对应的主机密钥，
再次连接另一台设备时，即使 root 密码正确，也会被旧密钥记录拦截。

## 修改

- MU300 电脑安装器与 E5 公共电脑更新工具不再加载或写入持久主机密钥缓存。
- 每次连接接受当前主机密钥，不再弹出首次信任提示或因旧缓存不一致停止。
- 旧的安装器缓存保留但不再读取；不修改其他 SSH 客户端的配置。
- root 密码鉴权、设备类型、内核版本、启动控制 CRC 和上传哈希检查保留。
- MU300 Python 与 Windows EXE 同步，6.18／7.2 安装包更新为 r5；E5 三机型安装包同步更新。

## 验证

- MU300 桌面安装器 34 项回归通过，新增“已有过期缓存仍不读写、不提示”的测试。
- E5 更新预检查同类回归通过，旧缓存未被访问或改写。
- 当前连接的 F50 使用 r5 Windows EXE，成功越过原先的密钥不匹配错误，进入更新确认。
  本轮在确认处输入 no，只验证连接与预检查，没有上传、写分区或重启当前 F50。
